# Aula 02
>
> (Gerenciamento de Lista de Jogos em Java)

## 📌 Exercício Prático do Slide (Console / CRUD em Vetor)

**Enunciado:**  
Desenvolva um sistema em Java, executado no console, para gerenciar uma lista de jogos. O sistema deve utilizar um array para armazenar os nomes dos jogos e apresentar um menu de opções com as seguintes informações:

1. Cadastrar jogo
2. Listar jogos
3. Atualizar jogo
4. Remover jogo
5. Sair

---

### 📋 Requisitos e Regras de Negócio

* **Gerenciamento Completo (CRUD):** O sistema deve permitir que o usuário cadastre, liste, atualize e remova jogos.
* **Validação de Atualização e Remoção:** Para atualizar ou remover, o usuário deverá informar o nome do jogo na lista.
* **Validação de Duplicidade:** Para cadastrar, deve-se verificar se o jogo já não existe na lista.
* **Laço Principal de Execução:** O programa deve permanecer em execução até que o usuário escolha a opção de sair (opção 5).
